## Reproduction

Run `npm.cmd ci --prefix .tooling --ignore-scripts` to restore the locked CLI packages. Preserve the committed skill source trees and references; do not blindly rerun mutable upstream skill installers during CI. Treat an intentional update as a new reviewed acquisition and update hashes/version evidence.

The `.tooling/sources` clones and `.tooling/packages` inspection archives are disposable acquisition caches; they are not application or deployment inputs. Keep `node_modules`, browser profiles, generated executable binaries and private screenshots out of commits and deployment artifacts. Do not import `.agents/skills` into application code.
